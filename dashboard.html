The engine

Three layers. One clear outcome.

The system separates facts from predictions so an ML model can never turn an unsafe candidate into a recommendation.

01

Screen

Validate the request and apply blood-group compatibility, age, donation recency and distance screening before the model sees a candidate.

02

Prioritize

The response model estimates which eligible donors are more likely to respond, while proximity and availability improve operational ordering.

03

Learn

Contact outcomes can be logged as training data so future models learn from real interactions instead of pretending synthetic data is real-world evidence.
