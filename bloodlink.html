Architecture

A hybrid pipeline, on purpose.

Blood compatibility is a medical fact, not a prediction — so it's never left to the model. The ML layer only ever ranks candidates who already passed every hard rule.

Stage 1

Rule filter

Blood-type compatibility, the 90-day donation gap, age eligibility, and distance cutoff. Fails any one, and a donor is never shown — no exceptions, no ML override.

Stage 2

ML ranking

A Random Forest scores every eligible donor on predicted response likelihood — trained on distance, availability, donation history, and past response time.

Stage 3

Scored output

ML probability and a proximity bonus blend into a single 0–100 compatibility score. Care teams get an ordered call list, not a black box.
